## Table Descriptions

### `users`
Core user identity table. Extended beyond Better Auth defaults with RBAC and admin fields.

| Column | Type | Notes |
|---|---|---|
| `id` | TEXT PK | UUID v4, generated by Better Auth |
| `name` | TEXT | Display name |
| `email` | TEXT UNIQUE | Lowercase, normalized |
| `emailVerified` | BOOLEAN | Set true after email verification |
| `image` | TEXT | Avatar URL (from OAuth or Gravatar) |
| `role` | ENUM | `guest \| user \| moderator \| admin` — default: `user` |
| `banned` | BOOLEAN | Soft ban — all sessions rejected if true |
| `banReason` | TEXT? | Human-readable reason (shown to user) |
| `banExpires` | TIMESTAMP? | NULL = permanent ban |
| `createdAt` | TIMESTAMP | Set by Better Auth |
| `updatedAt` | TIMESTAMP | Updated on any change |

### `accounts`
OAuth provider linkages + credential records.

| Column | Type | Notes |
|---|---|---|
| `providerId` | TEXT | `google`, `github`, `credential` |
| `accountId` | TEXT | Provider's user ID |
| `password` | TEXT? | bcrypt hash (credential provider only) |
| `accessToken` | TEXT? | OAuth access token |
| `refreshToken` | TEXT? | OAuth refresh token |

### `sessions`
Active user sessions. Token delivered via HTTP-only cookie.

| Column | Type | Notes |
|---|---|---|
| `token` | TEXT UNIQUE | Cryptographically random, 32 bytes |
| `expiresAt` | TIMESTAMP | Extends on activity (sliding window) |
| `ipAddress` | TEXT? | For session display in UI |
| `userAgent` | TEXT? | Device identification |

### `verifications`
Single-use tokens for: email verification, password reset, magic links.

| Column | Type | Notes |
|---|---|---|
| `identifier` | TEXT | email or userId |
| `value` | TEXT | SHA-256 hashed token |
| `expiresAt` | TIMESTAMP | 24h (verify), 1h (reset), 15m (magic) |

### `twoFactors`
TOTP secret and backup codes per user (1:1 with users).

| Column | Type | Notes |
|---|---|---|
| `secret` | TEXT | Base32 TOTP secret (encrypted in transit) |
| `backupCodes` | TEXT | JSON array of hashed one-time codes |
| `enabled` | BOOLEAN | True after user verifies first TOTP code |

### `auditLogs`
Immutable security event log. Never updated, only inserted.

| Column | Type | Notes |
|---|---|---|
| `action` | TEXT | Event type (see action catalog below) |
| `metadata` | TEXT | JSON — extra context |
| `userId` | TEXT? | Nullable (guest actions, pre-auth) |

## Indexes (Production PostgreSQL)

```sql
CREATE INDEX idx_sessions_user_id ON sessions(user_id);
CREATE INDEX idx_sessions_expires_at ON sessions(expires_at);
CREATE INDEX idx_sessions_token ON sessions(token);
CREATE INDEX idx_accounts_user_id ON accounts(user_id);
CREATE INDEX idx_accounts_provider ON accounts(provider_id, account_id);
CREATE INDEX idx_audit_logs_user_id ON audit_logs(user_id);
CREATE INDEX idx_audit_logs_created_at ON audit_logs(created_at DESC);
CREATE INDEX idx_audit_logs_action ON audit_logs(action);
CREATE INDEX idx_verifications_identifier ON verifications(identifier);
CREATE INDEX idx_verifications_expires_at ON verifications(expires_at);
```
